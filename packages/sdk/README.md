# @fairground/sdk

Algorand contract bridge for Fairground. Provides:

1. **VRF beacon helpers** (`src/vrf/beacon.ts`) — verified beacon app IDs, round targeting, result derivation
2. **AlgorandClient factory** (`src/algorand-client.ts`) — algokit-utils 9.2.0 client
3. **Generated ARC-56 clients** (`src/clients/`) — auto-generated by algokit-client-generator 6.0.1

## VRF Beacon

Applied Blockchain randomness beacon. Confirmed on-chain 2026-05-30:

- Mainnet app ID: `947957720`
- Testnet app ID: `110096026`
- Retention: 1512 rounds (~70 minutes). Keeper SLA: resolve within 60 minutes.

```ts
import { MAINNET_BEACON_APP_ID, targetBeaconRound, verifyFlipResult } from '@fairground/sdk';

const commitRound = targetBeaconRound(currentRound); // currentRound + 8n
const playerWon = await verifyFlipResult(beaconOutput32Bytes, saltHash32Bytes);
```

## Client Generation

Run after compiling contracts:

```bash
pnpm contracts:build     # puyapy -> artifacts/*.arc56.json
pnpm contracts:generate  # algokit generate client -> src/clients/*.ts
```

Never edit files in `src/clients/` by hand.

## AlgorandClient

```ts
import { createAlgorandClientFromEnv } from '@fairground/sdk';

const client = createAlgorandClientFromEnv();
// Reads ALGOD_URL, ALGOD_TOKEN, INDEXER_URL, ALGORAND_NETWORK from process.env
```
