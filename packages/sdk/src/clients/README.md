# Generated TypeScript Clients

This directory contains typed ARC-56 clients auto-generated by
`@algorandfoundation/algokit-client-generator@6.0.1`.

**Never edit files in this directory by hand.**

## Regenerate

```bash
# From repo root:
pnpm contracts:build    # runs puyapy, writes artifacts/*.arc56.json
pnpm contracts:generate # runs algokit generate client for each artifact
```

Or manually:

```bash
algokit generate client \
  packages/contracts/artifacts/HouseTreasury.arc56.json \
  --output packages/sdk/src/clients/HouseTreasuryClient.ts

algokit generate client \
  packages/contracts/artifacts/CoinflipContract.arc56.json \
  --output packages/sdk/src/clients/CoinflipContractClient.ts

algokit generate client \
  packages/contracts/artifacts/LeaderboardContract.arc56.json \
  --output packages/sdk/src/clients/LeaderboardContractClient.ts
```

## Expected files after generation

- `HouseTreasuryClient.ts`
- `CoinflipContractClient.ts`
- `LeaderboardContractClient.ts`

The root `src/index.ts` re-exports these once they exist.
