# Generated TypeScript Clients

This directory contains typed ARC-56 clients auto-generated by
`@algorandfoundation/algokit-client-generator@6.0.1`.

**Never edit files in this directory by hand.**

## Regenerate

```bash
# From repo root. Compile first: `make contracts-generate` only reads the committed ARC-56 files.
# Without --out-dir, puyapy 5.8.1 writes beside contract.py, not into artifacts/ -- compile each
# contract explicitly (pinned compiler: puyapy/compile.py:127-152 in algorandfoundation/puya @ v5.8.1).
(cd packages/contracts && \
  algokit compile python smart_contracts/coinflip/contract.py --out-dir artifacts && \
  algokit compile python smart_contracts/house_treasury/contract.py --out-dir artifacts && \
  algokit compile python smart_contracts/leaderboard/contract.py --out-dir artifacts && \
  algokit compile python smart_contracts/fairjackpot/contract.py --out-dir artifacts)
make contracts-generate
```

`pnpm contracts:build|generate` shell out to `algokit project run build|generate`, which is not
configured in `packages/contracts/.algokit.toml` ([project.run.*] is empty) — those wrappers don't
work. `make contracts-generate` is the one that does: it calls `algokit generate client` once per
contract, reading each contract's own `smart_contracts/<contract>/artifacts/*.arc56.json` (there is
no top-level `packages/contracts/artifacts/`) — see `Makefile` for the exact four commands.
