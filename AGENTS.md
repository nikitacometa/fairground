# Fairground — Agent Operating Guide

Concise reference for AI coding agents (Codex, remote Claude agents, etc.). CLAUDE.md is the authoritative source; this file is a field-deployable summary.

## What This Project Is

Provably-fair on-chain degen games on Algorand. VRF beacon app ID `947957720` on mainnet. First game: CometaFlip (coinflip), ~150-200 lines of Puya, 10-14 day build. Everything is TypeScript except the smart contracts (Python/Puya). Shared platform infrastructure from day one: house treasury, cross-game leaderboard, proof-card PNG engine.

**Design bible:** `docs/research/algorand-degen-games-2026-05.md` — read before any product decision.

## Critical Rules

### Version Pins — No Drift Allowed

All versions are pinned in `CLAUDE.md`. Never introduce a package version not listed there. Use `context7` MCP to verify API signatures before calling any versioned library.

### bigint Rule

All microALGO amounts, ASA amounts, Algorand app IDs, and round numbers are `bigint` in TypeScript. Never `Number`. API serializes `bigint` as `string` via JSON replacer.

### Never Edit Generated Files

`packages/sdk/src/clients/` is auto-generated by `algokit generate client`. Never edit by hand. Regenerate when contracts change.

### No Raw algosdk in Apps

All transaction group construction goes through `@fairground/sdk` typed clients. No raw algosdk group construction in `apps/game` or `packages/api`.

### Simulate Before Send

Call `simulate()` before `send()` on any non-trivial on-chain operation.

### VRF Commit Round

Minimum commit round is N+8. Never reduce. 48-hour player-triggered refund backdoor required in all game contracts.

### Box Storage MBR

Boxes must be pre-funded before access: `2500 + 400 * (key_len + val_len)` microALGO. Transaction fails with `invalid box reference` if MBR is not included. CometaFlip player box MBR = 35,000 microALGO.

### House Treasury First

`house_treasury` contract must be deployed before any game contract. All game contracts call `get_available_balance()` via foreign app ref. Max payout is enforced at `resolve()` time against live treasury balance.

### Geo-Block Before Launch

Blocked: US, UK, TH, ID, IN, BR. Thai block is non-negotiable (Bangkok legal exposure). Geo-block must be live before any Foundation RT or ecosystem newsletter submission.

### Test Quality

- Kill-the-mutant check: comment out a key SUT line, confirm at least one test fails.
- For every `mockResolvedValue`, add a `mockRejectedValue` sibling.
- Contract integration tests hit AlgoKit LocalNet Docker.
- Never commit if test count decreases.

## Keeper Architecture

4-second poll loop. Redis SETNX `keeperlock` (10s TTL, refreshed every 4s). Two Docker Compose instances: `fairground-keeper-primary` and `fairground-keeper-standby`. If primary crashes, standby acquires lock automatically. Keeper publishes to Redis pub/sub; Hono WS fans out to game clients.

## Compliance

This is house-banked gambling. Geo-block US/UK/TH/ID/IN/BR before launch. Frame as VRF tech demonstration in Foundation-facing communications. Never mention real-money gambling in xGov grant applications. Open-source contracts from day one.

## Commit Format

Lowercase verb, no type prefix. `add coinflip contract v1`. Update BOARD.md in same commit. Push after committing. Never `--no-verify`.
