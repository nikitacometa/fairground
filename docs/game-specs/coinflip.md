# CoinFlip Game Spec

**Contract name:** `CoinflipContract`  
**Source:** `packages/contracts/smart_contracts/coinflip/`  
**ARC-56 artifact:** `packages/contracts/artifacts/coinflip.arc56.json`  
**TS client:** `packages/sdk/src/clients/CoinflipClient.ts` (generated, never edit)

## Core Loop

1. Player connects wallet (Pera / Defly / Lute / Kibisis via `@txnlab/use-wallet-react`).
2. Player clicks Flip. Frontend calls `CoinflipClient.flip(salt_hash, referrer)` — an atomic group: payment to contract account + app call.
3. Contract stores session in box storage: `player_address → (vrf_round, bet_amount, salt_hash, referrer)`. Bet is escrowed in the coinflip contract during the pending phase.
4. Committed round = `current_round + 8`. VRF beacon output for that round is not yet known.
5. After round N+8 passes (~22 seconds), keeper calls `CoinflipClient.resolve(player_address)`.
6. Contract reads VRF beacon output via inner app call to app ID `947957720`.
7. Result: `sha256(beacon_output || player_salt) mod 2`. 0 = heads (win), 1 = tails (loss).
8. On `resolve()`: the escrowed bet is swept from the coinflip contract to the house treasury. Win: treasury pays player 1.96x bet via inner ALGO transfer. Loss: bet stays in treasury.
9. Box deleted after all inner transactions complete (deletion is the idempotency guard — no `claimed` field).
10. Proof card PNG generated by API and cached in Redis.
11. WebSocket event fans out to connected clients.

## Contract Responsibilities

**State:**

- Box per player: key = `player_address` (32 bytes), value = `vrf_round (uint64, 8B) + bet_amount (uint64, 8B) + salt_hash (bytes32, 32B) + referrer (address, 32B)` = 80 bytes. No `claimed` field — box deletion is the idempotency guard.
- Box MBR: `2500 + 400 * (37 + 80)` = 2,500 + 46,800 = **49,300 microALGO** (`flip:` prefix = 5 bytes → on-chain key = 37 bytes). Funded by the player's payment transaction.
- Global state: `house_treasury_app_id (uint64)`, `jackpot_rate_bps (uint16)`, `referral_rate_bps (uint16)`, `min_bet (uint64)`, `max_bet (uint64)`, `paused (bool)`.

## VRF Flow

```
block N:     player calls flip()
             contract stores committed_round = N + 8
             beacon app does NOT yet have output for N+8

block N+8:   VRF beacon receives entropy, computes output
             output is now queryable on-chain

block N+8+:  keeper calls resolve(player)
             contract makes inner app call to beacon app 947957720
             reads beacon.output(N+8) synchronously
             no oracle fee, no async callback

block N + 8 + BEACON_SETTLE_BUFFER (= N+12):
             resolve() asserts current_round >= commit_round + 4 before calling must_get()
             prevents calling must_get() before the beacon proof is written

block N + 61714+ (if keeper fails for ~48h at 2.8s/block):
             player (or anyone) calls refund()
             permissionless — any wallet can call this
             bet + BOX_MBR paid from the coinflip contract's own balance
             works even when house treasury is paused
```

**Beacon app ID:** `947957720` on mainnet (Applied Blockchain, free, live since Nov 17 2022).

Verify testnet beacon app ID via algorand MCP (`api_algod_get_application_by_id`) before writing any testnet integration tests. The research cites `110096026` but this must be verified. Never hardcode an unverified app ID.

**Idempotency key:** `(beaconRound, walletAddress)`. A second `resolve()` call on an already-claimed box fails at the AVM level — the box does not exist after deletion. No double-payout possible.

## Payout Math

- House edge: 2%
- Win probability: 50%
- Payout on win: 1.96x bet
- Expected value per bet: `0.5 * 1.96 + 0.5 * 0 = 0.98` — player gets back 98 cents per dollar bet on average.
- Referral deduction: 0.5% of bet sent to referrer address on resolve. Reduces net treasury income but is paid from the house edge (player always gets 1.96x on win).
- Jackpot deduction (v1.2+): 1% of bet to jackpot accumulator. Also from house edge.

**Solvency at 0.5 ALGO max bet, 2,000 ALGO treasury:**

- Max single payout: `min(0.5 * 1.96, 2000 * 0.01)` = `min(0.98, 20)` = 0.98 ALGO.
- Treasury can sustain: ~2,040 consecutive losses before hitting auto-pause threshold (which is 2,000 ALGO — but treasury grows with every loss, so this is a degenerate edge case).
- Realistic variance analysis: the standard deviation of the house's outcome over N bets at 2% edge is well-characterized. At 2,000 ALGO seed and 0.5 ALGO max bet, even a 3-sigma adverse run leaves the treasury solvent.

## Bankroll Sizing

| Treasury   | Max bet  | Max payout | Bets to drain (3σ adverse) |
| ---------- | -------- | ---------- | -------------------------- |
| 2,000 ALGO | 0.5 ALGO | 0.98 ALGO  | >10,000                    |
| 5,000 ALGO | 0.5 ALGO | 0.98 ALGO  | >25,000                    |
| 5,000 ALGO | 5 ALGO   | 9.8 ALGO   | ~500                       |

For CoinFlip: 2,000 ALGO seed + 0.5 ALGO max bet is the safe configuration. Increasing max bet without increasing treasury proportionally invalidates the solvency guarantee.

## API Surface

**POST `/games/coinflip/bets`**  
Body: `{ wallet: string, txnId: string, sessionId: string }`  
Creates pending bet record in Postgres. Returns `201` with session state.

**GET `/games/coinflip/state/:sessionId`**  
Returns: `{ status: 'pending' | 'resolved' | 'refunded', outcome?: 'heads' | 'tails', payout?: string, proofCardUrl?: string }`  
BigInt amounts serialized as strings.

**GET `/proof/:txnId`**  
Returns PNG. Generates on first request (500ms), serves from Redis cache on subsequent requests.

**WS `/ws`**  
Events pushed to client on connection:

- `{ type: 'resolved', sessionId, outcome, payout, proofCardUrl }`
- `{ type: 'jackpot', winner, amount }` (v1.2+)
- `{ type: 'treasury_paused' }`
