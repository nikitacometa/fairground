# @fairground/landing

Astro 6 marketing site for Fairground. Sections: hero, VRF explainer, games, live stats, leaderboard preview, FAQ.

## Stack

- Astro 6 (SSG/SSR)
- Tailwind CSS v4 via `@tailwindcss/vite`
- React islands (`client:load` / `client:visible`) for LiveStats and ProofCardDemo
- `@fairground/proof-card` — VrfResultCard for the proof card demo
- `@fairground/types` — shared API response types

## Setup

```bash
cp .env.example .env
pnpm dev
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `PUBLIC_SITE_URL` | Canonical site URL (e.g. `https://fairground.gg`) |
| `PUBLIC_APP_URL` | dApp URL (e.g. `https://app.fairground.gg`) |
| `PUBLIC_API_URL` | Fairground API base URL |
| `PUBLIC_PLAUSIBLE_DOMAIN` | Domain registered in Plausible (e.g. `fairground.gg`) |

## Analytics Note

The Plausible analytics snippet (`https://plausible.io/js/script.js`) is loaded
without an SRI `integrity` hash. This is intentional: Plausible updates `script.js`
in-place without changing the URL. A pinned hash would break the script on every
Plausible release. If a pinned hash is required by your security policy,
self-host the script using [Plausible's self-hosting guide](https://plausible.io/docs/self-hosting)
and pin the hash of your own copy.

All other external resources on this page are either inline or loaded from the
same origin — no other third-party scripts are present.

## Pages

- `/` — Main landing page
- `/sitemap-index.xml` — Auto-generated by `@astrojs/sitemap`

## Adding Pages

Create `.astro` files in `src/pages/`. Use `BaseLayout.astro` as the wrapper.
React islands go in `src/components/` and are imported with `client:*` directives.
